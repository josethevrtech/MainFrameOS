# MainFrameOS branding

The primary mark is a polished purple cube with blue edge lighting on a transparent background. The original PNG is stored at [cube.png](../images/usb/overlay/usr/share/mainframeos/branding/cube.png). Fastfetch uses the original image through the Konsole or Kitty image protocol where detected; other terminals receive a small purple and blue text cube. Protocol behavior follows the [Fastfetch logo documentation](https://github.com/fastfetch-cli/fastfetch/wiki/Logo-options).

The asset was generated using the built in image generation tool for this project. No external reference images were supplied. Keep the PNG alpha channel intact. The text fallback is a separately authored terminal representation, not a replacement for the rendered logo.

## Generation prompt

Create the official MainFrameOS logo asset. One singular iconic three dimensional cube, floating at an isometric angle, front and two upper/side faces clearly legible, subtle beveled edges, rich amethyst purple polished glass and metallic ceramic shader, physically realistic purple shading, restrained electric blue rim light and blue accents on a few edges. Sophisticated professional operating system brand. Minimal silhouette, crisp edges, excellent readability small in a terminal. Centered square composition with generous empty margins. True transparent background, no backdrop or floor, no text, no letters, no watermark, no extra objects. Produce one finished high quality square PNG logo with transparent alpha.
